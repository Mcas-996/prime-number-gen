# 线性筛法计算所有u64以内的素数

这个程序使用线性筛法（也称为欧拉筛法）计算所有u64以内的素数。

## 功能特点

- 使用高效的线性筛法算法
- 支持计算u64::MAX范围内的所有素数
- 分段处理大范围数字，避免内存溢出
- 每2秒显示一次进度，方便监控长时间运行
- 显示前10个和后10个素数作为示例

## 编译和运行

### 编译

```bash
cargo build --release
```

### 运行

```bash
./target/release/output_text.exe
```

## 算法说明

### 线性筛法

线性筛法是一种高效的素数筛法，时间复杂度为O(n)，空间复杂度为O(n)。与埃拉托斯特尼筛法不同，线性筛法确保每个合数只被标记一次，因此效率更高。

### 分段处理

由于u64::MAX的值非常大（18,446,744,073,709,551,615），无法直接创建这么大的数组。因此程序采用分段处理的方式：

1. 首先计算sqrt(u64::MAX)以内的素数
2. 然后使用这些小素数来筛分后续的区间

### 进度显示

程序每2秒显示一次当前处理的区间和已找到的素数数量，方便监控长时间运行的进度。

## 系统要求

- Rust 1.70或更高版本
- 至少2GB可用内存（实际使用量取决于处理进度）
- 支持u64类型的系统（大多数现代系统都支持）

## 性能说明

计算所有u64以内的素数是一个极其耗时的任务，可能需要数天甚至数周的时间才能完成。这个程序主要用于算法演示和测试。

## 注意事项

1. 程序运行时间非常长，不建议在生产环境中运行
2. 由于u64范围内的素数数量巨大，最终结果会占用大量内存
3. 程序可以随时中断，已计算的素数会丢失
